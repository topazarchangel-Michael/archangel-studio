# Archangel Angelic Code's — Phase 1 tester preview

Live: https://topazarchangel-michael.github.io/archangel-studio/

This branch holds only the **built static site** for the Phase 1 tester preview of the Archangel Angelic Code's studio
(ULTRA Intelligence), published with GitHub Pages.

- Everything runs in the browser; projects, assets and ULTRA memory are stored locally on each device.
- ULTRA uses a local, rule-based demo responder — no real AI model, no sign-in, no payments, no wallet.
- Credits are demo-only and have no cash value.

Source code is not published here.
