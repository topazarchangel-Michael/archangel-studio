Testing AI-built software

AI writes code fast, but it can be confidently wrong. Test everything before you share it.

The 5-minute check

  1. Click everything. Every button, every screen.
  2. Try silly input. Empty boxes, very long text, emoji, negative numbers.
  3. Phone size. Turn your phone sideways and back. Does it still fit?
  4. Reload. Is your data still there?
  5. Offline. Turn on aeroplane mode — what breaks?

Let ULTRA help test

  • Ask: "List 10 ways this app could break, then check each one."
  • Ask: "Write a test checklist for this app." Tick through it yourself.
  • Paste an error message exactly as it appears — it helps ULTRA find the cause.

Compare brains

  • If one AI gets stuck, switch brains in Settings and ask again. A second opinion often spots the bug.

For developers

  • Exported apps are plain web files, so you can add tests with free tools like Playwright (clicks through pages) or Vitest (checks functions).
  • Run tests before every publish. Keep a short list of bugs you've fixed so they don't come back.

Safety checks before sharing

  • No keys, passwords or private data in the code. Search the files for key, token and password.
  • Check images and text are yours or properly licensed (see Licences & credits).
