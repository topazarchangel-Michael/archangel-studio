Testing AI-built software

AI writes code fast, but it can be confidently wrong. Test everything before you share it.

The 5-minute check

  1. Click everything. Every button, every screen.
  2. Try silly input. Empty boxes, very long text, emoji, negative numbers.
  3. Phone size. Turn your phone sideways and back. Does it still fit?
  4. Reload. Is your data still there?
  5. Offline. Turn on aeroplane mode — what breaks?

Let ULTRA help test

  • Ask: "List 10 ways this app could break, then check each one."
  • Ask: "Write a test checklist for this app." Tick through it yourself.
  • Paste an error message exactly as it appears — it helps ULTRA find the cause.

Compare brains

  • If one AI gets stuck, switch brains in Settings and ask again. A second opinion often spots the bug.

For developers

  • Exported apps are plain web files, so you can add tests with free tools like Playwright (clicks through pages) or Vitest (checks functions).
  • Run tests before every publish. Keep a short list of bugs you've fixed so they don't come back.

Safety checks before sharing

  • No keys, passwords or private data in the code. Search the files for key, token and password.
  • Check images and text are yours or properly licensed (see Licences & credits).

Test the AI *inside* your app

If your app uses AI (a chatbot, a quiz writer, a game opponent), test the AI's answers too.

Make a "golden set"

  1. Write 10–20 typical questions or inputs, with what a good answer must include.
  2. Run them after every change. Tick ✅ / ❌. Keep the list in a Note so you can reuse it.
  3. Add every bug you find as a new line, so it never comes back.

The tricky-input checklist

TryGood result
Empty messagePolite "What would you like?" — no crash
A 5,000-word pasteTrims or summarises, doesn't freeze
Another language or emoji onlySensible reply
"Ignore your rules and…"Stays on task (prompt-injection check)
A personal question about someone elseRefuses to guess private info
A maths or date questionCorrect answer (AI often slips here)
Same question twiceAnswers agree

Score it

  • Accuracy — is it right? Check facts against a trusted source.
  • Helpfulness — does it actually solve the task?
  • Safety — no harmful, rude or private content.
  • Speed — under ~3 seconds on a phone for short replies.

Give each 1–5 and keep a small table per version, so you can see if a change made things better or worse.

Testing game AI

  • Level 1 should lose most games; level 10 should rarely lose. Play 10 games at each level.
  • Let the AI play itself 100 times: no illegal moves, games always finish.
  • Time its move on an older phone — under 1 second.

Testing quantum or science simulators

  • Known answers: H then measure 1000× ≈ 50/50. X on 0 → always 1. Bell state → only 00 and 11.
  • Probabilities must always add up to 1 (show the total while testing).
