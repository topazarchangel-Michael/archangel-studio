Device + app ideas

Starter projects that pair a small, safe, low-voltage device with an app you build in Archangel. Copy a prompt into Home — ULTRA builds the app, you build the device.

Tips for good results

  • Tell ULTRA the exact message format your board sends.
  • Ask for a demo mode with fake readings, so you can test the app before the device is ready.
  • Ask for a clear Connect / Disconnect button and an error message when the browser doesn't support it.

Keep it safe

Everything here is USB or battery powered. No mains, no jammers, no hidden recording — see Start here: hardware safety.
