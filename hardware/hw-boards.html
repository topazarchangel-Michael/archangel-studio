Boards: which one?

All three below are popular, cheap, well documented and use free, open tools. Pick one and stick with it while you learn.

BoardGood forLogic voltageWirelessFree tools
Raspberry Pi Pico / Pico WFirst projects, Python lovers3.3 VPico W: Wi-Fi + BluetoothMicroPython + Thonny, or Arduino IDE
ESP32 (dev board)Wi-Fi and Bluetooth gadgets that talk to apps3.3 VWi-Fi + Bluetooth LEArduino IDE, MicroPython, ESP-IDF
Arduino Uno (or open clone)Classic tutorials, tough 5 V pins5 VNone (add-ons exist)Arduino IDE
Not sure? ESP32 if you want your app to talk to it wirelessly; Pico if you'd like to write Python.

Setting up (about 15 minutes)

  1. Install the free Arduino IDE (arduino.cc/en/software) — or Thonny (thonny.org) for MicroPython on a Pico.
  2. Plug the board in with a data USB cable.
  3. Arduino IDE: Tools → Board → pick yours (for ESP32, add the board package via Boards Manager → "esp32"). Then Tools → Port.
  4. Open File → Examples → 01.Basics → Blink and press Upload. The on-board LED blinks — you're a hardware maker.

Pin words, in plain English

  • GND — ground, the "minus" side. Everything shares it.
  • 3V3 / 5V / VIN — power out (or in). Don't connect these to GND.
  • GPIO — general pins you control from code: on/off (digital) or a reading (analog).
  • ADC / A0 — pins that read a range (e.g. a light sensor).
  • TX / RX — serial talk lines. SDA / SCL — I²C, a two-wire bus many sensors use.

A Raspberry Pi (full computer) instead?

A Raspberry Pi 4/5 runs Linux and can host a web app itself — great for a home dashboard. It's more expensive and needs safe shutdowns. Start with a microcontroller unless you need a full computer.
