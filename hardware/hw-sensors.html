Sensors & data logging

Read the real world, show it in your app, and save it for charts.

The pattern every sensor project follows

  1. Read the sensor on the board every 1–10 s.
  2. Send a line of text over USB serial or Bluetooth: temp=22.4,hum=51.
  3. Show it in the app (big number + mini chart).
  4. Save readings with a timestamp in the app (IndexedDB / localStorage) and allow CSV export.

MicroPython example (Pico W + BME280 on I²C)

from machine import Pin, I2C
import time, bme280
i2c = I2C(0, sda=Pin(0), scl=Pin(1))
s = bme280.BME280(i2c=i2c)
while True:
    t, p, h = s.values
    print(f"temp={t[:-1]},hum={h[:-1]},pres={p[:-3]}")
    time.sleep(5)

Make the numbers trustworthy

  • Average 5 readings to smooth noise; ignore impossible values (e.g. −100 °C).
  • Calibrate: compare with a known thermometer, then add an offset in the app settings.
  • Timestamps come from the phone, not the board (most boards have no clock).
  • Heat from the board warms the sensor — mount it a few centimetres away.

Project ideas

  • 🌱 Plant monitor — soil moisture + light; alert when dry.
  • 🌡️ Room comfort — temp, humidity, CO₂ (SCD40); "open a window" tip.
  • 🚪 Door counter — PIR or break-beam; daily visitors chart.
  • 🔊 Noise meter for a classroom — microphone module; traffic-light display.
