First circuits (with schematics)

Each project shows a schematic (how it's connected) and the code. Power off while wiring. Pin numbers are examples — use any free GPIO and change the number in code.

How to read these diagrams

 ──      wire              GND / ⏚   ground (minus)
 ─[220Ω]─ resistor         ─▶|─      LED (long leg = + side, flat edge = −)
 ─o o─   push button        (GPIO n) a pin on your board

1. Blink an LED

 (GPIO 15) ──[220Ω]──▶|── GND
                    LED

Arduino IDE (works on ESP32, Pico, Uno — change the pin):

const int LED = 15;
void setup() { pinMode(LED, OUTPUT); }
void loop() { digitalWrite(LED, HIGH); delay(500); digitalWrite(LED, LOW); delay(500); }

MicroPython (Pico):

from machine import Pin
import time
led = Pin(15, Pin.OUT)
while True:
    led.toggle(); time.sleep(0.5)

2. A button

Uses the board's built-in pull-up resistor, so you only need the button.

 (GPIO 14) ──o o── GND
           button
 Pressed = LOW (0), released = HIGH (1)
const int BTN = 14, LED = 15;
void setup() { pinMode(BTN, INPUT_PULLUP); pinMode(LED, OUTPUT); Serial.begin(115200); }
void loop() {
  bool pressed = digitalRead(BTN) == LOW;
  digitalWrite(LED, pressed);
  if (pressed) { Serial.println("press"); delay(200); }
}

3. A light sensor (LDR)

A light-dependent resistor plus a fixed resistor make a "voltage divider" an analog pin can read.

  3V3 ──[ LDR ]──┬──[10kΩ]── GND
                 │
             (ADC pin, e.g. GPIO 26 / A0)
void setup() { Serial.begin(115200); }
void loop() { Serial.println(analogRead(26)); delay(250); }  // higher = brighter

4. Temperature & humidity (DHT22 or similar)

  3V3 ── VCC [sensor] DATA ── (GPIO 4)
  GND ── GND           (add 10kΩ from DATA to 3V3 if your module has no resistor)

Install the free "DHT sensor library" by Adafruit in Library Manager, open its example, set the pin, upload, and open Serial Monitor at 115200.

5. Something that moves: a small servo

Small hobby servos (SG90-size) are fine from USB 5 V for one servo. Bigger motors need their own supply — never run motors straight off a GPIO pin.

  5V  ── red    [servo]
  GND ── brown
 (GPIO 13) ── orange (signal)

Troubleshooting

  • Nothing happens → check GND is shared, the LED is the right way round, and the pin number matches.
  • Board not found → try another USB cable/port; install the CH340 or CP210x driver if your board's maker says to.
  • Weird readings → loose breadboard wire. Push everything in firmly.
