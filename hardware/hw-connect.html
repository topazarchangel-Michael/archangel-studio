Connect a device to your Archangel app

Your apps built in Archangel are web apps, so they can talk to hardware through two free browser features — no server, no keys.

WayWire?Works inBest for
Web SerialUSB cableChrome / Edge on desktop (and Android with some boards)Simple, reliable first link
Web BluetoothWireless (Bluetooth LE)Chrome / Edge on desktop and AndroidESP32 / Pico W gadgets
Wi-Fi (HTTP / WebSocket)WirelessAny browser on the same networkHome dashboards
Safari on iPhone/iPad doesn't support Web Serial or Web Bluetooth yet — use Wi-Fi, or Chrome on Android or desktop. Both features need https (your published app) or localhost, and the user must tap a button to pick the device.

The plan

 [sensor] ──▶ [board] ──USB / Bluetooth──▶ [browser app] ──▶ chart, alert, log

Keep messages tiny and readable: one line per reading, like temp:22.4 or press.

A. Web Serial (USB)

Board side: just Serial.println(...) at 115200 (see First circuits). App side — ask ULTRA to add this, or paste it in:

async function connectSerial(onLine) {
  const port = await navigator.serial.requestPort();      // must run from a button tap
  await port.open({ baudRate: 115200 });
  const reader = port.readable.pipeThrough(new TextDecoderStream()).getReader();
  let buf = '';
  for (;;) {
    const { value, done } = await reader.read(); if (done) break;
    buf += value; const lines = buf.split('\n'); buf = lines.pop();
    lines.forEach((l) => onLine(l.trim()));
  }
}
// Send to the board:  const w = port.writable.getWriter(); await w.write(new TextEncoder().encode('led:on\n'));

B. Web Bluetooth (ESP32)

Board side: in Arduino IDE open Examples → BLE → BLEnotify_ (ESP32 package). It advertises a service and sends a value you can update. App side:

const SERVICE = '4fafc201-1fb5-459e-8fcc-c5c9c331914b';   // from the example sketch
const CHAR    = 'beb5483e-36e1-4688-b7f5-ea07361b26a8';
async function connectBle(onValue) {
  const dev = await navigator.bluetooth.requestDevice({ filters: [{ services: [SERVICE] }] });
  const ch = await (await (await dev.gatt.connect()).getPrimaryService(SERVICE)).getCharacteristic(CHAR);
  ch.addEventListener('characteristicvaluechanged', (e) => onValue(new TextDecoder().decode(e.target.value)));
  await ch.startNotifications();
}

C. Wi-Fi

An ESP32 or Pico W can serve a tiny web page or JSON on your home network (Arduino example WiFi → SimpleWiFiServer). Your app then fetches http://<device-ip>/data. Keep it on your home network — don't open router ports to the internet.

Privacy and safety

  • Wi-Fi passwords go in the board's code on your computer only — never paste them into chat, shared apps or public repos.
  • Ask before you record anything about other people (sound, video, location).
  • Show a clear "Connected / Disconnected" state and a Disconnect button in your app.
